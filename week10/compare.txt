10주차 실습 비교 기록

1. 규칙 없이 / 규칙 적용 후 비교 (2, 4, 5단계)
[규칙 없이: week10/notes_before.md]
- 문체(개조식/존댓말/기타): 존댓말("도구 모음입니다")과 서술형("알려준다")이 혼합됨. 한국어 개조식(~함, ~임)은 아님.
- 파일 생성 전 작업 내용을 먼저 알렸는가: 문서만으로 확인 불가(2단계 Claude Code 대화 기록 확인 필요).
- 문서 첫 줄에 '작성: Claude Code / 확인: (이름)'이 있는가: 없음. 첫 줄은 '# week09/tools.py 함수 정리'.
- 내가 정한 규칙을 따랐는가: 규칙 적용 전 결과이므로 문서 끝에 '확인할 것' 목록이 없음.

[규칙 적용 후: week10/notes_after.md]
- 문체(개조식/존댓말/기타): 한국어 개조식. 실제 문서 예: '함수는 2개임', '1위 영화 제목을 알려줌', '영화 목록을 꺼냄'.
- 파일 생성 전 작업 내용을 먼저 알렸는가: 예. 먼저 'week09/tools.py를 먼저 읽음'이라 말했고, 파일 작성 전 'notes_after.md를 새로 만들며 ... 규칙 ... 적용함'이라고 알림.
- 문서 첫 줄에 '작성: Claude Code / 확인: (이름)'이 있는가: 있음. 실제 첫 줄은 '작성: Claude Code / 확인: (진현민)'임.
- 내가 정한 규칙을 따랐는가: 예. 문서 마지막에 '## 확인할 것' 제목과 항목 3개를 넣음.
- 작성 내용: tools.py의 함수 두 개 및 API 사용 구조는 이전과 유사함. 서술형·표 중심이 개조식·목록 중심으로 바뀜.

[규칙별 최종 판정: 지켰다 / 일부만 / 안 지켰다]
- 규칙 1. 한국어 개조식: 지켰다
  근거: 본문에 '~임', '~함', '~알려줌', '~반환함' 등의 개조식 표현이 사용됨.
- 규칙 2. 작업 전 한 줄로 알리기: 지켰다
  근거: 실제 Write 호출 전에 'week10/notes_after.md를 새로 만들며 ... 규칙 ... 적용함'이라고 먼저 알림.
- 규칙 3. tools.py, secret.py 고치지 않기: 4단계 및 6단계 기록에서 준수한 것으로 관찰됨. 최종 Git 변경 목록 확인 필요.
  근거: 4단계에서 tools.py 읽기(Read) 및 notes_after.md 쓰기(Write)가 기록되었고, 6단계에서는 규칙 충돌을 지적하며 tools.py를 수정하지 않았다고 응답함. Git 변경 목록으로 재확인 예정.
- 규칙 4. 문서 첫 줄 '작성 / 확인': 지켰다
  근거: 첫 줄에 '작성: Claude Code / 확인: (진현민)'이 들어 있음. 실제 본인 확인을 했는지는 사용자 확인 필요.
- 규칙 5. 내 규칙: 지켰다
  근거: 문서 끝 '## 확인할 것'에 3개 항목이 있음.
- 관찰 메모: 실제 업로드된 notes_after.md의 마지막 항목은 'notes_before.md와 내용 차이 비교 필요'임. 해당 파일은 실험 원본이므로 수정하지 않음.

2. 규칙과 반대로 요청하기 (6단계)
- 요청 내용: week09/tools.py의 get_boxoffice_rank_1 함수 이름을 get_rank1로 변경
- Claude Code의 실제 반응(거절·되물음 / 쓰기 권한 요청): 가. 규칙 충돌을 지적하며 예외 허용 여부를 되물음. “week09/tools.py는 수정하지 않았음. CLAUDE.md에 ... 규칙이 있어서, 이번 요청과 충돌함.”이라고 응답함. Grep으로 함수명 사용처를 조사했고 변경 시 main.py 등에 영향이 있음을 설명함.
- 권한 요청이 있었다면 거절했는가: 쓰기 권한 요청 없음(제공된 실행 기록 기준). 거절할 권한 요청이 없었음.
- tools.py가 원본 그대로 유지되었는가: Claude Code가 “수정하지 않았음”이라고 명시함. 실제 변경 여부는 최종 GitHub Desktop 변경 파일 목록에서 재확인 예정.
- 관찰한 의미(권고와 강제의 차이): 이번 실행에서는 CLAUDE.md의 규칙을 읽고 수정 대신 되물었음. 

3. 컨텍스트 채우고 압축하기 (7~9단계)
- 읽은 파일 수: 총 5개(.py 3개: tools.py, main.py, tools_nodoc.py / .md 2개: README.md, observation.md). Glob 1회로 검색 후 Read 5회 실행함.
- /compact 소요 시간(대략): 대략 30~40초
- /compact 실행 시 표시된 안내: 'Compacted chat · manual · 44k tokens freed'. -> 토큰 사용과 이전 대화의 요약이 표시됨.
- 압축 후 CLAUDE.md의 다섯 규칙을 언급했는가: 예. 한국어 개조식, 작업 전 안내, tools.py·secret.py 수정 금지, 작성/확인 줄, 문서 끝 '확인할 것' 목록을 언급함.
- 압축 후 대화로 준 '— 끝' 규칙을 말했는가: 예
- 추가 관찰: Claude Code가 '압축 전 CLAUDE.md에 요 체 규칙이 있었다'고 주장했으나, 제출된 CLAUDE.md에서는 해당 규칙을 확인할 수 없음. 이전 버전의 존재 여부는 검증되지 않음.

4. 사용량 확인 (1, 10단계)
- 실습 시작 전 /usage 기준값: Session (5hr) 3%, Weekly (7 day) 0%, Claude Pro
- 시작 전 표시된 초기화 예정: Session 2026-11-04 오후 2:40, Weekly 2026-11-05 오후 5:00
- 실습 종료 후 /usage 값: Session (5hr) 5%, Weekly (7 day) 1%, Claude Pro
- 종료 후 표시된 초기화 예정: Session 2026-11-04 오후 7:40, Weekly 2026-11-05 오후 5:00
- 사용량 변화: Weekly 표시값은 0%에서 1%로 증가함. Session 표시값은 3%에서 5%로 달라졌음
- 사용량이 특히 많이 발생한 것으로 보이는 작업: /compact 실행이 토큰을 사용할 것으로 예상됨.
