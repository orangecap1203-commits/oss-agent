# week09 관찰 기록

## 1번. 도구 호출 순서 관찰

AI에게 실습 폴더의 파일을 설명해 달라고 요청했을 때, 다음 순서로 도구를 호출했다.

| 순서 | 도구 이름 | 대상 및 작업 |
| --- | --- | --- |
| 1 | PowerShell | `Get-ChildItem -Recurse -Force`로 폴더의 파일 목록 확인 |
| 2 | Read | `average_pandas.py` 읽기 |
| 3 | Read | `average_plain.py` 읽기 |
| 4 | Read | `check.py` 읽기 |
| 5 | Read | `scores.csv` 읽기 |

- 도구 호출 횟수: **5회** (PowerShell 1회, Read 4회)
- 읽은 파일 수: **4/4개**
- 파일 수정 여부: **없음**
- 압축파일 `week09-sample.zip`은 목록에서 발견했지만 내부를 직접 읽지는 않았다.

## 2번. AI의 파일 설명 검증

실제 실습 파일의 내용을 AI 설명과 대조했다.

| 파일 | O/X | 확인한 내용 / 틀렸다면 무엇이 |
| --- | :---: | --- |
| `scores.csv` | O | 25개 데이터 행이 있고, 윤서준·임도현의 점수는 비어 있으며 신아름의 점수는 `미제출`이다. |
| `average_plain.py` | O | Python 기본 기능으로 과목별 평균을 계산하며, 빈 점수 및 숫자로 변환할 수 없는 점수는 제외한다. |
| `average_pandas.py` | O | pandas의 `to_numeric(errors="coerce")`와 `groupby().mean()`으로 결측값을 제외한 평균을 계산한다. |
| `check.py` | O | 빈 점수와 숫자가 아닌 점수를 찾아 출력한다. 첫 줄 주석은 평균 계산이라고 쓰였지만 실제 코드는 점검 기능이며, AI도 이 차이를 지적했다. |

네 파일 모두 AI의 설명이 실제 내용과 일치했다. 특히 `check.py`의 **주석이 잘못된 것**과 **AI 설명이 잘못된 것**은 구분해서 판단했다.

## 3번. 주석이 있는 `tools.py` 함수 설명

입력한 요청: `week09 폴더의 tools.py를 읽고, 각 함수가 무엇을 받고 무엇을 돌려주는지 설명해줘. 파일은 고치지마.`

| 함수 | 받는 값 | 돌려주는 값 |
| --- | --- | --- |
| `get_boxoffice_rank_1(date)` | `date`: 8자리 날짜 문자열 (예: `"20260824"`) | 그 날짜의 박스오피스 1위 영화 제목 문자열 |
| `get_movie_audience(date, title)` | `date`: 8자리 날짜 문자열, `title`: 영화 제목 문자열 | 해당 영화의 일일 관객 수 문자열 (예: `"123,456명"`), 또는 순위에 없다는 안내 문장 |

- 이 요청에서 확인한 도구 호출: **Read 1회** (`week09/tools.py`)
- 파일 수정 여부: **없음**
- AI는 제목을 정확히 비교한다는 점과, 빈 순위 목록이나 API 오류가 있을 때 예외가 발생할 수 있다는 점도 설명했다.

## 4번. 주석이 있는 원본과 주석 없는 사본 비교

`tools.py`를 복사해 `tools_nodoc.py`를 만들고 주석과 docstring을 제거한 뒤, 새 대화에서 **사본 파일만** 설명하도록 요청했다. AI는 `Read`로 `tools_nodoc.py`를 읽었고, 파일을 수정하지 않았다.

| 비교 항목 | 원본 (`tools.py`, 주석 있음) | 사본 (`tools_nodoc.py`, 주석 없음) |
| --- | --- | --- |
| 받는 값의 형식 | 날짜가 8자리 문자열이라고 명확히 설명 | 날짜를 문자열이라고 설명하고, 8자리 `yyyymmdd` 형식은 KOBIS API 관례로 추론 |
| 예시 값 | `"20260824"`, `"오디세이"` | `"20261027"`, `"영화제목"` |
| 돌려주는 것 | 1위 영화 제목, 또는 특정 영화의 일일 관객 수·안내 문자열 | 원본과 같은 반환값을 코드에서 추론해 설명 |
| 틀리거나 애매한 부분 | 예시 영화 제목과 관객 수가 실제 API 조회 결과인지는 확인되지 않음 | 날짜의 구체적인 형식이 코드만으로는 명시되지 않아 추론이 필요함 |

**관찰 결론:** 주석이 없어도 AI는 함수 이름과 코드를 보고 주요 기능과 반환값을 설명할 수 있었다. 그러나 입력 날짜 형식처럼 코드에 직접 드러나지 않는 사용 규칙은 주석이 있을 때 더 명확하게 전달되었다.
